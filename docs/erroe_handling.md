# Error Handling

## Unsupported ERP

Display:

"This attendance page is not currently supported."

## No Students Found

"Could not find the student list on this page."

## Image Processing Failure

"We couldn't read this attendance image."

## Student Not Matched

"Student could not be matched with the ERP."

## Ambiguous Match

"Multiple possible students found. Please select one."

## ERP DOM Changed

"ERP page structure may have changed. Attendance was not modified."

## Backend Unavailable

"AI service is currently unavailable."

## Principle

Never silently continue after a critical error.

Never mark a student absent because of an error.
