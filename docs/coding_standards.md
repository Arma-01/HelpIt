# Coding Standards

## General

Write clean, modular, maintainable code.

Do not create unnecessary files.

Do not duplicate logic.

Do not rewrite working code unnecessarily.

## JavaScript

Use modern JavaScript.

Prefer const/let.

Avoid global variables.

Use async/await.

Handle errors explicitly.

## Python

Use type hints.

Use Pydantic models.

Keep FastAPI routes thin.

Put business logic into services.

Use environment variables for secrets.

## Architecture

UI logic != business logic.

AI processing != ERP integration.

ERP adapter != student matching.

## Before modifying code

Understand existing architecture first.

Do not make destructive changes without necessity.

## Comments

Comment WHY, not obvious WHAT.
